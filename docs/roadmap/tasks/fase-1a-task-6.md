# Microtarea 1A.6 — Validación de estructura y checklist de salida

## Modelo recomendado
Haiku 4.5 para checklist/documentación breve o Sonnet 4.6 si necesita tocar archivos pequeños.

## Objetivo
Cerrar Fase 1A dejando una revisión clara de lo construido, los riesgos abiertos y la transición limpia hacia Fase 1B.

Esta tarea no debe abrir nuevas líneas de implementación fuera del alcance.

---

## Alcance exacto
Claude debe:
- revisar que la arquitectura creada en 1A.1–1A.5 sea coherente
- documentar qué quedó listo
- documentar qué falta para Fase 1B
- listar riesgos y supuestos
- preparar checklist breve de validación externa

Claude no debe:
- reabrir modelado grande
- añadir features nuevas
- improvisar integraciones posteriores

---

## Resultado esperado
Un documento o resumen operativo que permita arrancar Fase 1B sin reanalizar desde cero.

Debe responder:
- qué existe ya
- qué falta
- qué no debe tocarse al iniciar 1B
- qué comandos debe correr el usuario fuera de Claude

---

## Archivos permitidos
- docs/roadmap
- checklist de fase
- README específico si ayuda

## Archivos prohibidos
- schema grande nuevo
- UI pública nueva
- integraciones externas

---

## Entregable esperado
- checklist de cierre de fase
- riesgos abiertos
- lista de precondiciones para 1B

---

## Validación externa sugerida
Claude no ejecuta comandos. Debe proponer solo los necesarios.

---

## Cierre obligatorio
Termina con:
- Archivos creados/editados
- Qué hizo exactamente
- Qué no tocó
- Riesgos o pendientes
- Comandos a ejecutar fuera de Claude
