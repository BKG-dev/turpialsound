# Credenciales de pruebas

Este archivo ya no guarda contrasenas en texto plano.

Las credenciales QA locales/manuales/automatizadas se leen desde `.env.local`:

- Buyer: `QA_BUYER_IDENTIFIER`, `QA_BUYER_EMAIL`, `QA_BUYER_PASSWORD`
- Seller: `QA_SELLER_IDENTIFIER`, `QA_SELLER_EMAIL`, `QA_SELLER_PASSWORD`
- Admin: `QA_ADMIN_IDENTIFIER`, `QA_ADMIN_PASSWORD`

Para rehidratar las cuentas QA:

```bash
npx tsx scripts/setup-marketplace-qa-accounts.ts
```

Para seeds de desarrollo, usar las variables `DEV_*_PASSWORD` requeridas por
`prisma/seed-dev.ts`.
